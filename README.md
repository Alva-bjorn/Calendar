# Calendar 📅

A small desktop calendar app built with Electron, HTML, CSS and JavaScript.

The app displays the current day and month in a pixel-art inspired interface.

## ✨ Features

- Displays the current day
- Displays the current month
- Automatically updates the date when the app starts
- Custom pixel-art inspired UI
- Frameless and transparent Electron window
- Fixed window size
- Non-resizable window
- Custom background and typography

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- Electron

## 🎨 Design

The application uses a pixel-art inspired visual style with a purple/pink color palette.

The interface was designed to be small and minimal so it can function as a desktop widget.
